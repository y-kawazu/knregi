# KNレジ

バーコードまたはQRコードをカメラで読み取り、商品登録・会計・会計票印刷ができるシンプルなレジアプリです。iPad・iPhoneでの利用を想定し、AirPrint対応の印刷画面を呼び出せます。

## 主な機能

- カメラによるバーコード・QRコード読み取り
- 商品コードの手入力
- 商品マスターの登録・編集
- 数量変更、合計金額の自動計算
- 会計票の印刷
- 商品マスターと会計内容の端末内保存

## 開発環境

- Node.js 22.13.0以上
- pnpm
- React 19 / Next.js 16 / vinext / Vite

## 起動方法

```bash
pnpm install
pnpm run dev
```

表示されたローカルURLをブラウザーで開きます。カメラ機能はブラウザーの権限許可が必要です。

## 確認コマンド

```bash
pnpm run build
pnpm run lint
pnpm test
```

商品データと会計内容はブラウザーのローカルストレージに保存されます。
